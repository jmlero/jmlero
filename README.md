## What I work on

Most companies can build an AI agent. Few can run them safely at scale. I apply proven platform engineering to agents: golden paths, self-service and guardrails, so teams ship agents fast without losing control.

| | |
| --- | --- |
| **Run** | Agent runtimes and tooling on AWS and Kubernetes |
| **Govern** | Policies, guardrails, EU AI Act and DORA |
| **Trust** | Evals, observability, context as a product |
